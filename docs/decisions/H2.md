# H2 decisions (append-only)

[H2] "N/s" spirals mean N shots per second in total: broodmother 14/s = 7 events × 2 arms; galaxy arms 16/s = 4 events × 4 arms.
[H2] Ring and fan counts are shots fired; every ring adds a 2-slot gap at an rng-chosen slot (inward ring: 3-slot gap centred on the player's side).
[H2] Boss shots keep the existing shotSpeed(difficulty) scaling; the px/s values in the spec are base values.
[H2] Broodmother cloak: 2.0 s invulnerable and cloaked, teleports to rng x in [300, 980], figure-8 centre clamped to [340, 940] afterwards, 24-shot ring.
[H2] Path clocks start at the end of entry (lissajou, colossus steps, scrambler orbit, empress sweep), so each boss leaves its home point without a jump.
[H2] Homes moved to path starts: kraken (640,160), phoenix (640,150), scrambler (640,140). Scrambler orbit: radius 60, period 8 s (spec gives none), starting at the top.
[H2] Colossus steps 640→360→640→920→640 at the start of each 3 s segment, easing 0.8 s; cuckoo swarm 8 seekers, cap 16 alive per boss, 1 s.
[H2] Rotisserie patrol bounces at x 260 and 1020 at 80/100/120 px/s by phase; flame telegraph runs along the 60° start line from 50 px below the boss.
[H2] Kraken grab: two column strikes 2 s apart, x locked when each telegraph starts, width 140 for telegraph and beam. Slam beams and ink orbs use spec angles.
[H2] Kraken whirlpool: the gravity well is refreshed each tick with ttl = remaining attack time, so it lasts the 4 s attack and follows the boss.
[H2] Phoenix rebirth: onLethal sets hp to 50%, phase 2, invulnerable 2.5 s, clears enemy shots, kills hazards, gapMul 0.8, reborn cycle per spec.
[H2] Empress phase change: attack reset and 1.5 s invulnerability (as Dreadnought), all hazards cleared. Anim frame: phase 0–1 → 0, 2 → 1, 3 → 2.
[H2] Egg apocalypse: eggs skipped inside two 160 px lanes centred at x 400 and 880, drifting ±80 px over 8 s.
[H2] Mini cuckoo "both 30% faster" in phase 1 = pendulum duration ÷ 1.3 and gear speed × 1.3.
[H2] Mini guard: lance telegraph 0.8 s at the player's x (clamped 200–1080), dash to y 560 in 0.35 s, hold 0.2 s, return 0.6 s. Shield 300 set in onSpawn, restored to 200 at phase 1.
[H2] Mini brigadier salute: one column on the player, one at rng x in [200, 1080]; telegraph 0.9 s, beam 0.45 s.
[H2] Mini jelly: drip from three columns at x −120/0/+120 (5 eggs/s each, 2 s); pulse 24 boss_egg; phase 1 adds a 2-orb homing volley at spec angles 70 and 110.
[H2] Mini scarecrow: phase 1 gravity well (radius 300, power 90) refreshed each tick while alive.
[H2] Minions spawned by a boss carry parentId = boss id and die with it in onBossKilled; isMinion itself is unchanged.
[H2] Minions are spawned with counted: false, so they never consume the wave spawn plan.
[H2] Sprites keep the placeholder sizes and frame counts; art spans at least 80% of each box and stays inside it (a5.sprites).
