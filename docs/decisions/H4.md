# H4 decisions (append-only)
- [H4] Daily high scores live under `fowlplay.v2.scores.daily.YYYYMMDD`; campaign keeps the v1 `highscores` key; onslaught and boss rush use `fowlplay.v2.scores.<mode>`.
- [H4] Achievements are checked live from the run's state and again when the run is banked. Unlock corn is paid when an achievement unlocks; the run's corn (pickups + 1 per 20 000 points + 15 per boss) is paid when the run is banked at game over or victory.
- [H4] Victory followed by endless play banks only the part of the run since the previous bank (delta on corn, score and bosses).
- [H4] Lifetime counters (kills, bosses, food, golden chickens, overdrives) are added live from `runStats` deltas, so quitting mid-run keeps them.
- [H4] Twin hens share the `boss_hen` kind; the banner name tells them apart when a kill is recorded.
- [H4] Pause perks come from the last state `trackEvents` saw; `onStart` and `onRestart` reset the tracker so a stale run never shows.
- [H4] `playEffect(id)` is a module-level export of `audio/index.ts`, so menus can play the achievement and purchase chimes; `AudioSystem` is frozen.
- [H4] Menu themes: the draft track plays on the draft screen and on the hangar, loadout, codex and achievements screens (`setMenuTrack`); the title theme plays on the other menus.
- [H4] Overdrive hint "OVERDRIVE READY — C / SHIFT" is drawn above the fury bar and pulses while full (static when reduce-flashes is on).
- [H4] Ship stat bars on the cards are cosmetic, derived from the `SHIPS` numbers; the sim never reads them.
- [H4] Codex flavour lines are original one-liners written for this build.
- [H4] Locked ships can be browsed in the loadout carousel; START is disabled while a locked ship is shown.
- [H4] Each mutator toggle shows its score multiplier, taken from the `Score ×n` text of its description.
